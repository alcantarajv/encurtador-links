Encurtador de Links

API REST de encurtamento com redirecionamento em cache, controle de abuso por IP e estatísticas de acesso.

Java 21 · Spring Boot 4 · PostgreSQL · Redis · Docker

Endpoints

POST /api/v1/links Cria um link curto. Corpo: {"originalUrl": "..."}, com expiresAt opcional.
GET /{código} Redireciona (302) para a URL original e registra o acesso em segundo plano.
GET /api/v1/links/{código}/stats Total de cliques, visitantes distintos, série diária e principais origens.
GET /actuator/health Estado da aplicação.
